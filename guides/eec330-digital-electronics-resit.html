Section I
Number Systems
20 marks

1. Define: Binary number, Number system, Bit 3 marks

  • Number system: a structured way of representing quantities using a set of symbols (digits) and a base (radix) that fixes how many symbols exist and what each position is worth.
  • Binary number: a number expressed in base 2, using only the digits 0 and 1, where each position's weight is a power of 2.
  • Bit: a "binary digit" — the smallest unit of digital information, holding exactly one of two values, 0 or 1.

3b. (A6C2)₁₆ = (?)₈ = (?)₂ 2 marks

  • Hex→binary is direct: each hex digit → 4 bits. A=1010, 6=0110, C=1100, 2=0010.
  • Binary = 1010 0110 1100 0010

3c. (B.2C)₁₆ = (?)₈ = (?)₁₀ 2 marks

  • To decimal: B = 11 (integer part). Fraction: 2×16⁻¹ + C×16⁻² = 2/16 + 12/256 = 0.125 + 0.046875 = 0.171875

3d. (10111100111.011)₂ = (?)₁₆ = (?)₈ 2 marks

  • To hex: group in 4s from the binary point, padding the outer groups with zeros. Integer part (11 bits) pads to 12: 0101 1110 0111 = 5,E,7. Fraction 011 pads to 0110 = 6.
  • To octal: group in 3s. Integer pads to 12 bits: 010 111 100 111 = 2,7,4,7. Fraction 011 stays 3 bits = 3.
(10111100111.011)₂ = (5E7.6)₁₆ = (2747.3)₈

If your printed paper shows a slightly different bit string, the method above — pad to a multiple of 4 (hex) or 3 (octal) counting outward from the binary point — is what earns the marks.

4. Timing diagram → truth table → logic network for F(A,B,C) 4 marks

  • Read the timing diagram column-by-column: at each time slice, note the level (high/low) of A, B, C simultaneously, then read F's level in that same slice.
  • Build the truth table row by row from these 8 (or however many) time slices — each unique ABC combination gives one row.
  • Once you have the truth table, treat it exactly like 3a/3b: write minterms where F=1, K-map, and simplify to get the logic network.

This one depends on reading your specific waveform image precisely — the marks are mostly for correct table construction, not the final gate count. Go slice by slice, don't skip any transition.

2. Using a D flip-flop to build a JK flip-flop 6 marks

  • Tip given: compare the two characteristic equations. D-FF: Qₙ₊₁ = D. JK-FF: Qₙ₊₁ = JQ̄ₙ + K̄Qₙ.
  • Since a D flip-flop just outputs whatever is on D at the next clock edge, we need external combinational logic that computes D = J·Q̄ₙ + K̄·Qₙ and feeds that into the D input.
  • Circuit: take J and Q̄ into an AND gate; take K̄ (i.e., K through a NOT gate) and Q into a second AND gate; OR the two AND outputs together; connect that OR output to the D flip-flop's D input; feed the flip-flop's own Q output back as one of the AND gate inputs (that's the "Qₙ" feedback).
  • This feedback loop is the key structural idea: the flip-flop's current state feeds back into the combinational logic that decides its next state.
D = JQ̄ + K̄Q → this drives the D input; the D-FF then naturally reproduces JK behaviour

2c. Logic circuit of the full adder 4 marks

  • Build it from two half adders: HA1 takes A, B → produces partial sum P = A⊕B and partial carry G1 = AB.
  • HA2 takes P and Cᵢₙ → produces final sum S = P⊕Cᵢₙ and partial carry G2 = P·Cᵢₙ.
  • Final carry-out: OR the two partial carries — Cₙ = G1 + G2 = AB + Cᵢₙ(A⊕B), which is algebraically identical to AB + ACᵢₙ + BCᵢₙ.
Two XOR gates (cascaded) for S, two AND gates + one OR gate for Cₙ — the standard two-half-adder full adder.
Deep Dive
Why K-maps and Flip-Flops Work
The reasoning behind the recipes — this is what actually sticks

K-maps: what a "grouping" really means

  • A K-map is just a truth table redrawn so that every adjacent cell differs by exactly one variable (that's why the column headers go 00, 01, 11, 10 — not 00, 01, 10, 11. That ordering is called Gray code, and it's the entire trick).
  • Because neighbouring cells differ by one bit, two adjacent 1-cells means: "this output is 1 regardless of that one differing variable." That's literally the Boolean law XY + XY̅ = X in visual form — grouping two cells lets you drop a variable.
  • Grouping 4 cells drops 2 variables, grouping 8 drops 3, and so on — always powers of 2. A group of 3 or 5 is invalid because it doesn't correspond to any clean algebraic cancellation.
  • Rule of thumb for exam speed: always circle the biggest legal group first (containing powers-of-2 cells: 1,2,4,8,16), even if it overlaps a group you already made. Overlap is fine and often required — the same 1 can belong to multiple groups.
  • Corners of the map count as adjacent to each other (the map wraps around, top-to-bottom and left-to-right) — this trips people up constantly. Don't forget wrap-around groupings.
Exam tip

Every 1 must be covered by at least one group, but you don't need every possible group — just enough groups to cover every 1 with the fewest, largest groups (this gives the minimal SOP).

Don't-cares: the "free lunch" of K-maps

  • A don't-care exists because some input combination is guaranteed to never happen in that system (e.g. in BCD, codes 10–15 never occur, so any function of a BCD digit has don't-cares at those minterms).
  • You are never forced to include a don't-care in a group. Only use it when it helps you form a bigger group than you could otherwise. Leave the rest as if they were 0.
  • This is why don't-cares almost always shrink the final expression compared to treating them strictly as 0.

Flip-flops: why the "characteristic equation" is the real syllabus

  • Every flip-flop type is really just "a memory cell plus some input logic." The characteristic equation tells you exactly what the next state (Qₙ₊₁) will be, given the current state (Qₙ) and the inputs.
  • D flip-flop: Qₙ₊₁ = D. This is the simplest possible memory — whatever you put on D shows up on Q at the next clock edge. No dependency on the old state at all.
  • JK flip-flop: Qₙ₊₁ = JQ̄ₙ + K̄Qₙ. Read this as two cases OR'd together — "if J=1 AND we were 0, go to 1" OR "if K=0 AND we were 1, stay 1." This is precisely why JK avoids the "forbidden state" problem that a simpler SR latch has (J=K=1 gives a well-defined toggle, not an undefined race).
  • The conversion trick (D→JK, or any flip-flop→any other): write the target flip-flop's characteristic equation, then design combinational logic that computes that exact equation from the inputs you have, and feed it into your available flip-flop's data input. This "excitation table" method generalizes to converting between any two flip-flop types — it's not just a JK/D party trick.
Common exam variant

You could just as easily be asked to build a T flip-flop from a JK (T flip-flop: Qₙ₊₁ = T⊕Qₙ, achieved by tying J=K=T), or a D from a JK (tie J=D, K=D̄). Same method, different target equation.

Full adder: why two half adders is the standard build

  • A half adder only handles 2 inputs (A,B) — it can't accept a carry-in, so it's useless alone for multi-bit addition.
  • Chaining two half adders lets the second one absorb the carry-in from the previous stage — this is exactly how ripple-carry adders are built for wider numbers (chain N full adders to add N-bit numbers).
  • Recognizing "S = XOR of all inputs, carry = majority function" is a pattern that reappears constantly in digital design — it's worth memorizing structurally, not just as a formula.
